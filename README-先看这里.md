这是 2026-10-04 导出的现有网站源码，可以在自己电脑上修改。

线上地址：https://猫猫鱼.icu

## 先跑起来

1. 解压整个压缩包，例如放到 `D:\Projects\maomaoyu-source`。不要在压缩包里直接编辑。
2. 电脑已安装 Python 3：双击 `START-PREVIEW.bat`，窗口保持开启，然后在浏览器打开 http://127.0.0.1:8000 。按 Ctrl+C 停止。
3. 没有 Python 时，也可以先用浏览器打开 `dist/index.html` 看界面和转盘；文件网址下本地保存行为因浏览器而异，正式编辑时建议使用本地 HTTP 预览。
4. 用你习惯的代码编辑器打开整个 `maomaoyu-source` 文件夹，改完保存，在浏览器刷新。若旧样式没更新，试 Ctrl+F5。

如需手动启动：在源码文件夹打开 PowerShell，执行：

```powershell
py -3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

如果电脑的 Python 命令是 `python`，将 `py -3` 换成 `python`。
8000 端口被占用时，把端口换成 8001，并打开 http://127.0.0.1:8001 。

这些预览只监听你自己的电脑。改本地文件不会自动修改线上网站。

## 想改什么，就找哪个文件

| 文件 | 改什么 |

| `dist/index.html` | 标题、普通文案、页面结构、按钮和弹窗 |
| `dist/style.css` | 颜色、字体、大小、间距、手机布局 |

这里的 `dist` 是实际源代码，不是需要重新生成的构建文件夹。没有 npm 安装或打包步骤。

### 例子：换公共菜单

编辑 `dist/app.js` 最开头的 `DEFAULTS`。三个键分别是：

- `breakfast`：早餐
- `lunch`：午餐
- `dinner`：晚餐

例如想把午餐换成三种，只修改 lunch 对应的数组：

```js
lunch: ['番茄鸡蛋面', '饺子', '黄焖鸡米饭']
```

保持整个对象中的括号和英文逗号正确；这行不是让你替换整份 app.js。用英文引号和英文逗号，每个名字不要重复。建议每餐 8～16 项，过多时转盘上的字会变小。

如果菜名中需要英文单引号，可以用双引号包住整个菜名。

修改 DEFAULTS 会改变公共菜单，以及从未保存过个人菜单的新浏览器的初始菜单。它不会覆盖此前已经保存的私人菜单，这是保护用户修改的预期行为。

### 例子：换主色

`style.css` 开头的 `:root` 中：

- `--paper`：页面底色
- `--ink`：主要文字色
- `--red`：按钮、重点文字色
- `--red-dark`：主按钮鼠标悬停色

部分木头和指针绘制颜色还直接写在 CSS／Canvas 绘图代码中，更完整的换色可以让 Astra 帮你统一处理。

## 改完怎么更新到正式网站

当前网站托管在 ChatGPT Sites，阿里云负责域名。阿里云域名页面不是上传 HTML 的地方，也不需要每次更新都改 DNS。

这个源码包没有发布密钥，不会自己向线上上传。保留原始压缩包作为一份基线备份。

### PC 上的 Astra 有 Sites 工具

把你修改的文件或整个文件夹交给它，说：

“请把我的改动合并到现有猫猫鱼转盘 Site，project_id 是 appgprj_6ac20b2a1940819189afc88c19c10c2c。先打开现有项目，检查线上是否有比这份源码更新的改动，保留项目身份和公共访问权限，检查后发布。不要新建网站，也不要重新绑域名。”

### PC 上的 Astra 没有 Sites 工具

可以先让它帮你本地修改和预览。要上线时，把改好的源码压缩包发回这个有 Sites 工具的会话，我来同步到原项目并发布。

如果以后希望完全脱离聊天、自己点一次按钮就上传，需要另行配置你自己可用的发布渠道；本次源码导出没有迁移托管或改动 DNS。

### 改坏怎么办

本地：从原始压缩包重新解压，或用编辑器/Git 撤回修改。

线上：把错误表现、报错或改过的源码发给 Astra。根据原项目当前版本修复后重新发布；不要删除项目重建。原基线源码已在 Site 的远程仓库和此次压缩包中保留。

## 保存数据的边界

- 私人菜单保存在浏览器 localStorage，键是 `maomaoyu-meals-v1`。
- 手机、电脑、本地预览、正式域名、平台预览域名各自独立，不自动同步。
- 不要为了测试公共菜单随便清除正式网站数据，以免丢失私人菜单；可使用本地预览或无痕窗口测试默认菜单。
- 临时勾选、重抽排除和上次结果仅本次打开有效；私人菜单和避免重复开关会保存。
